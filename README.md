# Road-Trip-Web_Game
A visual web remake of a Java console road trip simulator, built with HTML, CSS, and JavaScript. Manage your fuel, cash, stamina, and group tension to survive random events and reach the beach!

(Built as a collaborative project with a friend.)

Gameplay

You are the only one in your friend group who can drive. During a brutal summer heatwave, your friends convince you to take a road trip to the beach. Each day brings new surprises and difficult choices that affect your stats.

Win Condition: Survive the road trip and reach the beach with enough resources left to celebrate.

Lose Condition: Run out of resources or let group tension get too high, leaving you stranded in the summer heat.

Features

Resource Management: Manage stamina, fuel, money, and morale as they drain over time.

Tension System: Bad situations increase tension and can lead to losing the game.

Random Event System: Dynamic events driven by RNG that challenge your decision-making.

Daily Progression: Stats drain each day, forcing you to plan ahead.

Tech Stack

HTML – Game structure and layout

CSS – Styling and visual presentation

JavaScript – Game loop, state management, and random event logic

How to Run

Clone or download this repository.

Put the images in one folder.

Open index.html in any web browser.
